> **Powered by IBM Watsonx.ai Granite Models**

## ✨ Features

### 🎯 Core Capabilities

- **Automated Code Analysis**: Analyzes repository structure, dependencies, and code patterns
- **Blast Radius Analysis**: Predicts the impact of modifying any file by tracing downstream dependencies and computing mathematical risk levels
- **Architecture Visualization**: Generates Mermaid.js class and sequence diagrams
- **Tech Stack Detection**: Automatically identifies languages, frameworks, and tools
- **Security Assessment**: Detects potential vulnerabilities and security issues
- **Installation Guides**: Creates step-by-step setup instructions
- **Legacy Code Analysis**: Special "Archaeologist Mode" for legacy codebase modernization
- **Interactive Chat**: Ask questions about the analyzed repository
- **File Explorer**: Browse and analyze individual files with AI insights

### 🚀 Advanced Features

- **Two Analysis Modes**:
  - **Basic Mode**: Standard repository analysis with diagrams and documentation
  - **Archaeologist Mode**: Deep legacy code analysis with refactoring strategies
- **Blast Radius Interactive Visualizer**: Visualizes code coupling and dependency propagation using physics-based force-directed layouts
- **Real-time Processing**: Live updates during analysis
- **Dark Mode Support**: Beautiful UI with light/dark theme
- **Export Reports**: Download analysis as Markdown files
- **Responsive Design**: Works on desktop, tablet, and mobile

### 💥 Blast Radius Impact Prediction

The **Blast Radius Analysis** engine is an enterprise-grade system that calculates the consequences of modifying any file:

- **Coupling & Instability Metrics**: Computes Efferent Coupling ($C_e$), Afferent Coupling ($C_a$), and Instability ($I = \frac{C_e}{C_a + C_e}$) to assess structural reliability.
- **Mathematical Impact Score (0-100)**: Evaluates risk based on direct dependents, transitive propagation depth, centrality, complexity, and critical module flags (e.g., auth, payments).
- **Interactive vis-network Graph**: Color-coded nodes by risk level (🟢 Low, 🟡 Medium, 🟠 High, 🔴 Critical) and language, with animated propagation waves.
- **AI-Powered Mitigation Plans**: Automatically recommends target unit tests, integration paths, and precautions generated by Watsonx.ai Granite Instruct.

## 🏗️ Architecture

### Technology Stack

**Frontend:**

- React 18 with TypeScript
- Vite (Build tool)
- TailwindCSS (Styling)
- vis-network (Force-directed physics simulation for Blast Radius graphs)
- Mermaid.js (Architecture diagram rendering)
- Axios (HTTP client)

**Backend:**

- Node.js with Express
- IBM Watsonx.ai SDK
- GitHub API integration
- GraphEngine (Custom DFS/BFS/Tarjan's SCC traversal algorithms)

**AI/ML:**

- IBM Watsonx.ai (Granite 3-8B Instruct model)
- IBM Cloud IAM authentication

### System Flow

```
User Input (GitHub URL)
    ↓
GitHub API (Fetch repo data)
    ↓
File Selection & Graph Structure Calculation
    ↓
IBM Watsonx.ai + GraphEngine Analysis
    ↓
Response Processing & Self-Healing Diagram/Graph Generation
    ↓
UI Rendering (Reports, vis-network, Mermaid, Chat)
```

## 🔧 Installation

### Step 1: Clone the Repository

```bash
git clone <your-repo-url>
cd codepulse-ai
```

### Step 2: Install Dependencies

```bash
npm install
```

This will install all required packages including:

- React and React DOM
- Express server
- IBM Watsonx SDK
- Mermaid.js
- TailwindCSS
- And other dependencies

### Step 3: Configure Environment Variables

Create a `.env` file in the root directory:

```bash
cp .env.example .env
```

Edit the `.env` file with your credentials:

```env
# IBM Watsonx.ai Configuration
IBM_WATSONX_API_KEY=your_ibm_cloud_api_key_here
IBM_WATSONX_PROJECT_ID=your_project_id_here
IBM_WATSONX_URL=https://us-south.ml.cloud.ibm.com
IBM_WATSONX_MODEL_ID=ibm/granite-3-8b-instruct

# GitHub Configuration (Optional - for higher rate limits)
GITHUB_TOKEN=your_github_personal_access_token
```

### Step 4: Start the Application

You need to run both the backend server and frontend development server:

**Terminal 1 - Backend Server:**

```bash
npm run server
```

**Terminal 2 - Frontend Dev Server:**

```bash
npm run dev
```

The application will be available at:

- Frontend: `http://localhost:5173`
- Backend API: `http://localhost:3001`

| Variable                 | Description                  | Required | Default                             |
| ------------------------ | ---------------------------- | -------- | ----------------------------------- |
| `IBM_WATSONX_API_KEY`    | Your IBM Cloud API key       | Yes      | -                                   |

| `IBM_WATSONX_MODEL_ID`   | AI model to use              | No       | `ibm/granite-3-8b-instruct`         |
| `GITHUB_TOKEN`           | GitHub personal access token | No       | -                                   |
| `VITE_BACKEND_URL`       | Backend API URL              | No       | `http://localhost:3001`             |

### Obtaining IBM Watsonx Credentials

1. **API Key:**
   - Go to [IBM Cloud Console](https://cloud.ibm.com)
   - Navigate to "Manage" → "Access (IAM)" → "API keys"
   - Click "Create an IBM Cloud API key"
   - Copy and save the key securely

2. **Project ID:**
   - Go to [Watsonx.ai](https://dataplatform.cloud.ibm.com/wx/home)
   - Open your project
   - Click "Manage" tab
   - Copy the "Project ID"

3. **Service URL:**
   - Default: `https://us-south.ml.cloud.ibm.com`
   - For other regions, check IBM Cloud documentation

### GitHub Token (Optional)

To increase API rate limits:

1. Go to GitHub Settings → Developer settings → Personal access tokens
2. Generate new token (classic)
3. Select scopes: `public_repo`, `read:user`
4. Copy token and add to `.env`

## 🎮 Usage

### Basic Workflow

1. **Open the Application**
   - Navigate to `http://localhost:5173`

2. **Enter Repository URL**
   - Paste any public GitHub repository URL
   - Example: `https://github.com/facebook/react`

3. **Select Analysis Mode**
   - **Basic Mode**: For modern repositories
   - **Archaeologist Mode**: For legacy codebases

4. **Wait for Analysis**
   - The system will fetch repository data
   - AI will analyze the code
   - Diagrams and reports will be generated

5. **Explore Results**
   - View architecture diagrams
   - Read AI-generated documentation
   - Browse file explorer
   - Chat with AI about the code

### Analysis Modes

#### 🔵 Basic Mode

Best for modern, well-structured repositories:

- **Summary**: High-level project overview
- **Tech Stack**: Detected technologies
- **Key Components**: Main modules and files
- **Installation Guide**: Setup instructions
- **Architecture Diagrams**: Class and sequence diagrams
- **Security Assessment**: Vulnerability scan
- **Developer Notes**: Additional insights

#### 🟣 Archaeologist Mode

Specialized for legacy code analysis:

- All Basic Mode features, plus:
- **Business Logic Extraction**: Plain English explanations
- **Coupling Analysis**: Identifies tightly coupled code
- **Refactoring Strategies**: Microservices migration plans
- **Safety Net Generation**: Unit test suggestions
- **Technical Debt Assessment**: Code quality issues

### Using the Chat Feature

1. Complete a repository analysis
2. Click on the "Chat" tab
3. Ask questions like:
   - "How does authentication work?"
   - "Explain the database schema"
   - "What are the main API endpoints?"
   - "How can I add a new feature?"

### Exporting Reports

1. Complete analysis
2. Click "Export MD" button
3. Markdown file will be downloaded
4. Contains all analysis results

## 🔌 API Documentation

### Backend Endpoints

#### POST `/api/watsonx/generate`

Generate text using Watsonx.ai Granite Instruct models.
**Request:**

```json
{
  "prompt": "Analyze this code...",
  "maxTokens": 2000
}
```

**Response:**

```json
{
  "text": "Generated analysis..."
}
```

#### POST `/api/blast-radius/analyze`

Generates dependency mapping, risk levels, and suggested unit tests for a target file.
**Request:**

```json
{
  "owner": "string",
  "repo": "string",
  "targetFile": "string",
  "branch": "string",
  "token": "string?"
}
```

**Response:** `BlastRadiusResult` (risk score, stability metrics, affected nodes, AI explanations).

#### POST `/api/blast-radius/graph`

Calculates entire repository import structure, detecting circular cycles and critical components.
**Request:**

```json
{
  "owner": "string",
  "repo": "string",
  "branch": "string",
  "token": "string?"
}
```

**Response:** `DependencyGraph` nodes and edges, along with cycle diagnostics.

#### GET `/api/health`

Health check endpoint.
**Response:**

```json
{
  "status": "ok",
  "service": "CodePulse AI Watsonx Proxy"
}
```

## 🐛 Troubleshooting

### Common Issues

#### 1. "Failed to authenticate with IBM Cloud IAM"

**Solution:**

- Verify your `IBM_WATSONX_API_KEY` is correct
- Check if the API key has expired
- Ensure you have Watsonx.ai service access

#### 2. "Diagram syntax error"

**Solution:**

- The AI sometimes generates invalid Mermaid syntax
- The system now validates diagrams before rendering
- Invalid diagrams will show "No diagram generated"

#### 3. "GitHub API rate limit exceeded"

**Solution:**

- Add a `GITHUB_TOKEN` to your `.env` file
- This increases rate limit from 60 to 5000 requests/hour

#### 4. "Backend server not responding"

**Solution:**

- Ensure backend is running: `npm run server`
- Check if port 3001 is available
- Verify `VITE_BACKEND_URL` in frontend

#### 5. "Module not found" errors

**Solution:**

```bash
rm -rf node_modules package-lock.json
npm install
```
