### 1. The Blast Radius Instability Formula
Bob successfully co-developed the mathematical instability calculation based on Efferent Coupling ($C_e$) and Afferent Coupling ($C_a$):
$$I = \frac{C_e}{C_a + C_e}$$
Integrating this directly with dynamic graph centrality and cyclomatic complexity estimations produces a highly accurate, deterministic 0-100 code modification risk score.

### 2. The Self-Healing Mermaid.js Parser
To eliminate standard LLM syntax generation bugs, Bob programmed a real-time regex-based sanitation pipeline in [services/watsonx.ts](file:///h:/IBM%20Hack/gitsight-ai/services/watsonx.ts):
*   `class A(B)` $\rightarrow$ `class A` (Strips parenthesized Python inheritance)
*   `List<T>` $\rightarrow$ `List~T~` (Converts generics to Mermaid tildes)
*   `nn.Module` $\rightarrow$ `nn_Module` (Replaces invalid package dots)
